# Python PDF Splitter Utility

Aplikasi utilitas Python sederhana untuk memanipulasi dokumen PDF, seperti memecah setiap halaman menjadi file terpisah atau mengekstrak rentang halaman tertentu.

## Fitur Utama
* **Split All Pages:** Memecah dokumen PDF besar menjadi file individu per halaman.
* **Extract Range:** Mengambil rentang halaman spesifik dan menyimpannya ke file baru.
* Dibangun menggunakan library `pypdf`.

## Cara Menjalankan
1. Instal dependensi:
   `pip install pypdf`
2. Jalankan skrip:
   `python main.py`
